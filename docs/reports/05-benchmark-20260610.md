# Thunder vs Nginx HTTP 纯性能对比 (picohttpparser)

> 日期: 2026-06-10 | 工具: wrk 4.1.0 | CPU: i9-12900H, governor=performance
> 
> 只比 HTTP 编解码吞吐，不比业务逻辑 (/hello/hello 含 JSON+protobuf 无意义)。
> ur(io_uring) 后端已移除，Nginx 数据复用旧测。

```
                        端点                  RPS         延迟       vs 旧版    vs Nginx
──────────────────────────────────────────────────────────────────────────────
Thunder (ev)              /hello/raw         353,275      288μs     +64%      178%    🏆
Nginx 1.27.5 (1 worker)   /echo              198,219      503μs        —      100%
Thunder 旧版 (ev)          /hello/raw         216,040      460μs        —      109%
──────────────────────────────────────────────────────────────────────────────
```

## 结论

- picohttpparser 换 http_parser: **RPS +64%, 延迟 -37%**
- 超 Nginx **78%**
- 2.3MB ModuleRaw.so (纯 `{"code":0,"msg":"ok"}` echo, 零业务)

## 测试命令

```bash
wrk -t4 -c100 -d15s http://127.0.0.1:30006/hello/raw
```
